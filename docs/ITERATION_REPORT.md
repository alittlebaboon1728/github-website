## 运行与模型接入

```bash
npm install
npm run dev       # http://localhost:5173
npm run build
npm start         # http://localhost:4173，静态资源 + API
```

将 `.env.example` 复制为 `.env.local`，按需配置后重启服务：

```dotenv
GITHUB_TOKEN=
AI_BASE_URL=https://你的模型服务/v1
AI_API_KEY=
AI_MODEL=
OBSERVATORY_DATA_DIR=.data
OBSERVATORY_PERSISTENCE=on
OBSERVATORY_COLLECT=off
```

AI 的三个变量必须同时填写。服务需支持 `POST {AI_BASE_URL}/chat/completions`、`messages`、`response_format: {"type":"json_object"}`，返回 `choices[0].message.content` 中的 JSON。远程服务要求 HTTPS，本机服务支持 HTTP；填写服务商真实的模型标识。没有默认假模型或固定推荐演示。密钥只在服务端读取，禁止写入 `VITE_*`。

模型会收到用户需求与公开 README。最多保留 8 条需求，每条 500 字；候选来自最多 3 组 GitHub 查询，合并后读取前 10 个候选的 README 前 16,000 字符。模型输出需要带连续原文引用，服务端验证候选身份、原文存在性及硬条件检查结果。缺少资料的硬条件不进入主推荐，偏好未知单独标识。引用验证不能完全消除语义误读，所以保留原文与时间供核对；未实际测试项目，不作能力保证。

AI 请求限制为每地址每分钟 4 次、最多 2 个不同检索同时执行；重复内容合并、结果缓存 10 分钟。模型调用每阶段超时 60 秒，GitHub 单次超时 15 秒。浏览器取消会中止页面请求并忽略旧结果；已在执行的共享检索仍可在服务端完成并进入缓存。

## 内容与历史持久化

`.data/` 已加入忽略规则，保存每个博客源上次成功结果、动态缓存和 stars 快照。JSON 通过串行更新、临时文件与原子替换写入，支持重启恢复；**仅一个 Node 进程拥有同一目录**。生产环境需要设置持久卷的绝对目录，定期备份。无状态/多副本部署应使用单一采集进程，或将存储接口换成共享数据库。

```bash
npm run collect   # 可由外部定时器运行，采集默认累计榜与博客
```

生产服务设置 `OBSERVATORY_COLLECT=on` 可在启动时和每 6 小时采集默认范围；Vite 不启动后台定时器。其他语言/用途范围在访问时分别采集。快照保留约 95 天，按 UTC 日首次观察保存；当天重复刷新不制造历史。`OBSERVATORY_PERSISTENCE=off` 或写入失败时，页面明确禁用增长趋势。

独立 `npm run collect` 命令也会拥有数据目录，运行时应先暂停使用同一目录的开发/生产服务。持续运行的网站优先使用进程内 `OBSERVATORY_COLLECT=on`；外部定时器可以请求运行中服务的 `/api/observatory/trends` 与 `/api/observatory/blogs`，避免多个写入进程共享 JSON 目录。

累计榜范围是公开、未归档项目在 GitHub 搜索结果中按 stars 排序的前 30 个，不是全站完整排名。增长比较同一查询/算法中起止都存在的仓库，总 stars 净变化 = 期末 − 期初，允许负数；不是新增关注人数。起止时间会明确显示；曲线只连接实际观测点，不补点。日/周/月窗口缺少足够历史时显示正在积累数据；不显示未经核实的名次变化。近 30 天创建榜的日期边界每天变化，因此仅用于累计榜视图。

博客来源在 `server/blogs.mjs` 配置，仅服务端抓取固定官方来源：

- `https://github.blog/open-source/feed/`
- `https://code.visualstudio.com/feed.xml`

来源缓存 15 分钟，单源失败使用该源最后成功缓存并显示日期；没有缓存则显示失败，不影响其他来源。保留原文摘要节选，未伪装成中文 AI 摘要；排除未来发布日期。关联项目只使用来源配置或文章内实际仓库链接。

近期动态缓存 2 分钟，浏览器每 3 分钟检查，后台不轮询，恢复前台再检查。只使用公开事件最近一页（最多 100 条原始事件）中能构造可核对原始链接的事件。真实冒烟确认当前部分 PR 使用 `action: merged` 和缩减字段；只在 API URL 与实际编号一致时映射网页地址，推送链接使用实际 SHA。没有标题就显示编号，不填补用户名、计数或假事件。动态失败可使用标明抓取日期的持久缓存。
