# Liquid Glass 视觉更新

日期：2026-11-01。用户认为青柠参考版仍廉价，要求参考苹果 Liquid Glass 重新设计；本次只修改视觉与材质交互。

## 参考与设计

实际阅读了 [Apple 官方设计介绍](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)，并在浏览器中查看官方材质视频封面。采用其内容与控件分层、同心圆角、环境透色、方向反光与克制用色原则。

色板收敛为银灰 `#f3f4f5`、阅读面 `#fafbfc`、石墨字 `#202326`、次级字 `#5c6268` 和少量青绿强调 `#28685e`。保留既有中文艺术标题、Instrument Serif 英文与 Manrope 正文字体。布局仍是左搜索、右动态，下方试用与两列项目瀑布流；手机单列。

- 顶部改为单一悬浮玻璃条，选中导航浮于其上，减少每个导航链接的重复边框。
- 搜索框保留透明胶囊，使用弧面内亮边、接触阴影及独立圆形操作按钮。
- 玻璃边缘通过 CSS 遮罩绘制方向高光，中心保留清晰内容。鼠标移动时高光按当前位置变化；内容、文字和图片不扭曲。
- 项目卡和动态面板使用更轻的材质与圆角；主要按钮保持语义颜色，已收藏状态保留填充图标。
- 弹窗与菜单采用更密的材质，以保证重叠内容仍可读。真实 Excalidraw 内部控件不覆盖。
- 深色使用石墨色和冷灰反光。移动端保留可点击尺寸；减少动画/透明度、后台与窗口失焦时停止动态高光。不支持背景模糊时使用实色回退。

这是网页的视觉近似实现，采用 CSS 背景模糊、遮罩与镜面高光，没有宣称复现 Apple 原生的实时光线折射。没有新增依赖、背景素材请求或持续动画循环。
