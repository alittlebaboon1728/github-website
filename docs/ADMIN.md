# 简易管理后台

日期：2026-11-02。

在服务器本机的 PowerShell 运行：

```powershell
cd G:\github_website
npm run lan:start
```

网站：`http://localhost:4173/`；后台：`http://localhost:4173/admin`。同一服务同时提供两个页面，关闭终端后继续在后台运行。服务停止或电脑重启后，先执行启动命令再打开后台；管理页不能在自己的服务器已停止时启动它。

查看状态：`npm run lan:status`。停止网站：`npm run lan:stop`。更新源码后先 `npm run build`，再停止、启动。内网地址以状态命令输出为准；后台只允许通过服务器本机的 `localhost`、`127.0.0.1` 或 IPv6 回环地址打开，不通过 WLAN 地址开放管理操作。

## 页面功能

- 查看运行时间、内存、中文概括文件数、缓存占用、已准备页面数、保存的试用数、模型配置状态和数据目录。
- 按分类/关键词筛选已登记范围，只看未完成或异常范围；展开每页中文就绪数量、更新时间和错误重试时间。
- 单独更新指定范围或安排所有范围更新。操作只排入现有后台队列，继续提供原有中文页；失败的上游请求仍遵守冷却时间，不清空磁盘缓存、不强制重生全部中文概括。
- 暂停或恢复常驻更新。暂停立即阻止后续页启动，当前页完成后停止；已保存内容继续可读。暂停仅对本次进程有效，重启恢复原配置。
- 每五秒读取状态，可手动关闭自动读取。标签页隐藏时停止轮询；断线保留上一次结果并提示重连。底部可以复制启动、状态、停止命令。

中文模型、磁盘持久化或 `DISCOVERY_BACKGROUND` 未开启时，后台显示真实状态并禁用更新按钮。密钥仍只在服务端配置，后台不读取或显示密钥文件正文。

接口位于 `/api/admin/status`（GET）和 `/api/admin/library`（POST）。除回环连接和本机 Host 检查外，写操作还校验同站点来源与每次进程生成的管理令牌；不提供删除缓存、执行终端命令或修改模型凭据接口。

## 实现与验证

管理页为独立 Vite 入口 `admin.html`，界面代码在 `src/admin/`；服务端检查和路由在 `server/admin.mjs`。开发地址 `http://localhost:5173/admin` 同样可用，读取 `.data/`，正式服务读取 `.data-lan/`。

93 项服务端、74 项浏览器和生产构建通过。真实正式服务检查 1440/390px × 深浅主题，后台约 0.53–0.56 秒读取完成，无页面错误、横向溢出或自动写操作；实测暂停/恢复后已恢复原运行状态，暂停期间数据分类仍返回 12 张中文卡。内网地址的首页与项目接口为 200，后台页面和管理接口为 403。

复验脚本 `node scripts/verify-admin.mjs`，默认目标 `http://localhost:4173`，支持 `ADMIN_BASE_URL`。脚本读取真实页面并短暂暂停/恢复当前正在运行的更新器，最终保留原运行状态；不点击手动更新按钮。报告与四张截图位于 `.build/admin/`。
