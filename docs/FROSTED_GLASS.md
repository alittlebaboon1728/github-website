# 通透磨砂玻璃

2026-11-01。用户要求恢复搜索框磨砂，并为按钮和卡片统一材质；随后指定参考 [青柠起始页](https://www.limestart.cn/)，强调透明感。

## 实现

原磨砂被 `refined-theme.css` 中不透明背景和 `backdrop-filter: none` 覆盖。本轮新增 `src/frosted-glass.css`，在布局主题之后统一加载。保留排版、两列瀑布流、现有组件和业务逻辑。

- 参考站点的胶囊搜索框、背景透色与轻薄边缘。基础浅色填充约 19%，深色约 22%；降低白色反光和阴影，避免厚重白块。
- 搜索框与面板采用 30px 背景模糊，按钮采用 18px；文字、图标与图片自身不模糊。背景为本地 CSS 青绿、雾蓝和柔和暖色层，没有壁纸下载依赖。
- 导航、操作按钮、分类、收藏、卡片、动态面板、榜单、阅读弹窗与问答输入共用材质；主要操作与选中状态保留绿色区分。作为内容链接的标题和图片继续融入卡片，不额外套按钮边框。
- 弹窗与菜单采用更高填充，保持叠层阅读清晰。真正的 Excalidraw 编辑器控件保持其自有样式。
- 鼠标悬停时搜索框轻微上浮；触屏与减少动画偏好不位移。减少透明偏好及不支持背景模糊的浏览器使用实色回退。
