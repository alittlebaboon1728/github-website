## 内容规范

以已有 Excalidraw 案例为基准，目标是让第一次接触项目的人理解用途，并完成一个具体的小任务。

1. **认识项目**：一句话用途、适用人群、练习目标、预计用时与必要前提。
2. **看懂路径**：3–6 个可独立访问的步骤，每一步有操作和可观察的结果。不能强制看完说明才允许试用。
3. **动手体验**：依据项目特点选择可操作的教学演示、流程图、真实在线工具或已有视频。本站生成的模拟演示与官方软件明确区分。Excalidraw 保留真实编辑器、保存和 SVG 导出。
4. **开始正式使用**：安装或在线使用的具体步骤、限制和下一步；安装命令必须来自读取的 README，不执行命令。
5. **可核对的来源**：README 原文片段、获取时间、生成时间、模型及资料链接。引用核验只能验证原文存在，不能保证模型语义判断完全正确。

生成只能由用户明确点击触发。打开快速了解、访问试用页、刷新和浏览列表均不生成。重复请求合并；成功结果持久保存并复用。资料不足、配置缺失、上游失败须显示明确状态并可重试。

## 界面方案

沿用站点配色：银灰 #f3f4f5、纸白 #fafbfc、石墨 #202326、低饱和绿 #28685e，体验区使用浅紫 #f0eff7；深色沿用现有主题变量。标题沿用站点字体，中文正文 15–16px，说明行长控制在约 70 字符。

桌面：项目与目标 → 大体验区 / 任务步骤 → 正式上手 / 来源。手机按目标、体验、步骤、正式上手排列。项目试用列表突出 Excalidraw 的真实白板与已生成的项目，以内容区分各个体验。

```
返回试用列表                       项目来源
项目名称 / 一句话用途 / 完成什么
┌─────────────────────┬────────────┐
│ 可操作的体验区域     │ 任务步骤    │
│ 演示 / 流程 / 白板   │ 操作与结果  │
└─────────────────────┴────────────┘
正式开始使用                       资料与边界
```

设计复核：采用项目专属的体验内容作为视觉主体，不采用通用 FAQ 模板。ui-ux-pro-max 的相关引导规则用于保留跳过/回看能力；站点已有颜色与字体优先于通用设计系统建议。

## 生成边界

GPT 读取经公开性校验的仓库和 README，返回结构化使用指南及可选的自包含 HTML 交互示例。HTML 仅在无同源权限的沙箱 iframe 内执行，不允许联网、读取本站存储、跳转顶层页面或执行安装命令；外部体验和视频仅使用输入资料中确实存在的链接，在独立标签页打开。不将文字模型的输出称为已制作的真实视频。

普通中文项目卡与问答继续使用原有 DeepSeek 配置；试用生成使用独立 TRIAL_AI_* 配置与 gpt-6.1-sol。开发机可从 api.txt 的 gpt 标签读取密钥，绝不返回浏览器或记录在文档中。

## 接口与部署

- `GET /api/observatory/trials`：生成结果摘要和正在执行/失败的任务；不调用模型。
- `GET /api/observatory/trials?repo=owner%2Frepo`：项目体验及生成状态；不调用模型。
- `POST /api/observatory/trials`：`{ "repo": "owner/repo" }`；主动生成、相同项目合并。已有结果直接返回。
- 主动重做可增加 `"regenerate": true`，前端先说明将替换旧结果、使用模型额度。生成失败保留旧结果。
- 同源与 JSON 校验，请求不超过 2 KB；每地址每分钟最多 6 次提交，同时最多两个项目生成。单次模型请求最多 180 秒，内容校验失败修正一次。离开页面停止轮询，服务端仍完成任务。
- `.data/project-trials.json` 保存最近 64 个成功项目，服务重启后复用。未启用持久化时只在当前进程保留；执行中的任务不跨进程恢复，重启后可主动重试。

配置示例（由服务器读取）：

```dotenv
TRIAL_AI_BASE_URL=https://api.openai.com/v1
TRIAL_AI_MODEL=gpt-6.1-sol
TRIAL_AI_API_KEY=
```

本机使用用户明确提供的 `https://api.yorozumoon.cn/v1` Chat Completions 兼容服务；`GET /v1/models` 实际确认该服务列出 `gpt-6.1-sol`。用户给出的 curl 中 `gpt-5.6-luna` 仅作为协议示例，没有用于本功能。OpenAI 官方文档页面在此网络返回 403；接入依据用户提供的协议、该服务模型列表及真实生成结果，不据此承诺 OpenAI 官方账号的同名模型可用性。

服务端提示词、数据与 README 由该模型服务处理。HTML 沙箱不具备同源、弹窗、下载和顶层跳转权限，CSP 禁止外部资源与网络请求；只开放由本站注入的高度上报，父页面核对窗口来源、消息类型和实例标记并限制高度。模型生成代码仍不可视为任意软件的真实执行环境。

## 实现入口

- `server/trial-model.mjs`：独立模型与凭据读取、请求超时、响应边界与脱敏错误。
- `server/trials.mjs`：Excalidraw 基准提示词、结构/命令/引文/链接校验、任务合并、持久缓存。
- `server/trial-http.mjs` / `server/observatory.mjs`：受保护的生成和读取接口。
- `src/components/TrialLaunch.tsx`：快速了解入口。
- `src/components/TrialLibrary.tsx` / `TrialPage.tsx` / `trials.css`：试用列表、练习工作台、响应式与主题。
- `src/trials.ts`：前端协议、沙箱文档与受控尺寸通信。
- `src/ProjectDetail.tsx`：保留真实 Excalidraw，增加练习目标和清单、折叠延伸介绍。
