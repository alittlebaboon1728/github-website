# 视觉更新 · 2026-11-01

面向浏览 GitHub 开源项目的中文用户。搜索、数据、推荐、收藏、路由和试用行为保持现状；本轮仅调整展示结构与样式。

## 设计方向

以开源观测站的真实活动图表和可操作白板作为首屏内容，保留中文艺术标题。收紧导航与首屏的比例，让搜索更明确、项目内容更易读。白板使用独立的浅紫画布区域，主题入口置于其外，避免所有内容都被包进同一种卡片。

- 颜色：雾白 `#f8faf9`、纯白 `#ffffff`、墨色 `#202d2b`、青绿 `#216859`、中灰 `#626f6b`、浅紫 `#f0eff7`。深色主题使用深石板底色与低饱和青绿。
- 字体：保留本地 Editorial CN 中文标题与 Instrument Serif 英文副标题；Manrope 用于界面及项目名，中文正文使用系统无衬线字体。正文和来源信息增加可读字号。
- 结构：内容最大宽度 1248px，宽屏内边距 40px；首屏左侧标题与搜索、右侧活动面板；桌面保持双列瀑布流，600px 以下单列。
- 交互：导航使用低对比选中底色；搜索以边框、焦点环反馈；卡片悬停改变边框与阴影，图片轻微缩放；弹窗轻微出现动画。保留原有动态组件及暂停控制，减少动态偏好关闭新增动画。

```
品牌                 导航               工具

艺术标题 + 搜索              活动图表 + 消息

白板介绍                    可交互白板
设计工具             开发工具             AI 工具

分类                              语言 / 排序
项目卡                           项目卡
```

设计复核：通用技能搜索两次均返回与开发者目录不相符的行业配色与字体，未采用。以上方案按实际内容和既有用户偏好制定，使用技能通用的对比度、焦点、响应式与减少动态检查原则。避免玻璃材质、全站装饰渐变、虚构指标或抽象占位配图。

## 实现边界

主视觉集中在 `src/refined-theme.css`，在组件样式后加载；`DiscoveryShelf.tsx` 仅增加白板展示区域的容器。原文件备份位于 `.build/ui-refresh-backup/`。未改动任何业务处理函数或服务端代码。未新增依赖、字体下载或图片资源。
