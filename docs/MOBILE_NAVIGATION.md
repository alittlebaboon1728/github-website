# 手机导航与筛选控件

更新：2026-11-02。针对用户提供的手机截图修正图标位置、导航收放和按钮样式，沿用现有银灰/石墨玻璃材质。

## 当前行为

- 手机发现页的圆形筛选入口固定为 44×44px，SVG 水平和垂直居中。榜单筛选入口隐藏系统的 details 标记，改用带 16px 内侧留白的 SVG 箭头；展开时箭头旋转，文字和图标保持对齐。
- 820px 及以下，主题和菜单入口使用 44×44px 玻璃按钮，保留 8px 间距、细边框、按下/悬停/展开状态与可见键盘焦点。
- 手机导航一直保留 DOM，以透明度、位移、轻微缩放和裁切进行 240ms 收放；关闭时立即禁用点击和键盘访问，退出画面继续播放。支持收起途中重新展开，减少动态效果时直接切换。
- 切页和浏览器后退不重置菜单状态，不重建顶部导航及水滴；菜单保持展开，选中水滴在四个入口间连续移动。展开面板为绝对定位，不推挤正文。
- 点击导航外的区域、在外部触摸滑动或使用滚轮时自动收起；不阻止原有点击/滚动。路由恢复滚动位置和普通 scroll 事件不会误关。Escape 收起并将键盘焦点交还菜单按钮。
- 手机/桌面断点变化重新对齐水滴，桌面导航不附加手机展开面板样式；同一页面内保留手机的菜单选择状态。完整刷新后手机菜单默认关闭。

## 实现位置

`ExplorerApp.tsx` 保留菜单状态并管理外部交互监听；`SiteNavigation.tsx` 管理断点与关闭语义；`site-navigation.css` 管理布局和可逆过渡；`frosted-glass.css` 管理按钮材质与筛选控件对齐。筛选箭头由 `FilterDisclosure.tsx` 提供。已有 `useDropletIndicator` 的连续水滴动画继续复用。

## 验证与复现

生产构建通过。发现/榜单共 33 个浏览器用例已覆盖通过；最后一轮 32 项通过，剩余一项因等待外部样本图片 load 超时，改为等待 DOM 和可操作导航后独立复验通过。`scripts/verify-mobile-navigation.mjs` 使用实际正式页面、实际 GET 和触摸输入，检查 360/390/600/820/821/1440px × 深浅主题共 12 组、48 次连续切页：顶部几何位置和菜单状态稳定，水滴移动/落点正确、收放中间帧可见，外部点击/滑动关闭正常，图标居中，无页面异常、横向溢出或浏览器 POST。报告及手机截图保存在 `.build/mobile-navigation/`。
