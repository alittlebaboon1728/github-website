# 全站轻薄玻璃与试用栏目规范

2026-11-01 用户指出重复白板入口、按钮内边距缺失、深色实底主按钮与选项卡材质不一致，要求全站统一；随后明确白板入口应在下方，项目栏目标题应稳定而正文因项目不同。

页面只保留一个白板入口，位于“动手体验”标题旁。顶部与侧栏不再重复提供该操作。项目介绍、使用方法、动手体验、正式使用、相关资料与使用须知由 `projectTrialSections.ts` 提供固定栏目名称；项目用途、任务、步骤及说明来自各自内容。原生 Excalidraw 与生成式试用共用这些标题。

后续复现规范已落实为 `shared/project-trial-template.json` 与共享阅读/步骤组件，生成页也使用下方唯一体验入口。原打勾步骤侧栏已移除；玻璃内容的独立合成保留在体验容器。沙箱按钮从宿主读取材质变量，避免模型自行画回深色实底。最新实现与 Marked 实测见 [PROJECT_TRIAL_TEMPLATE.md](PROJECT_TRIAL_TEMPLATE.md)。

材质继续使用现有银灰/石墨背景、低饱和墨绿文字和 Liquid-Glass-HTML 真实边缘折射。所有主按钮改为中性的半透明玻璃，强调操作用文字及透色强度区分，不再使用深绿色实底、厚内高光或凹凸暗边。浅深主题均使用共享材质变量；减少透明度时按用户偏好回退实色。

最新控件例外（2026-11-01，用户明确要求）：动态面板的暂停/刷新、搜索齿轮/搜索只显示图标，卡片原文/中文切换只显示文字链接。它们使用共享 `bare-control`，同时从玻璃通用规则和折射调度排除；悬停、按下、选中及展开状态也不恢复圆圈底或阴影，点击区至少 44px，键盘焦点仍可见。此例外优先于下方旧的“所有控件使用玻璃”约定。

用途分类改为单个玻璃水滴滑动，与导航复用 `useDropletIndicator`；不同宽度及换行通过缩放和平移衔接，连续点击从当前位置继续，减少动画时直接定位。原生 `select` 在支持 `appearance: base-select` 的浏览器中启用统一的玻璃菜单、圆角选项、勾选与悬停反馈；不支持时保持原生选择及键盘行为。菜单采用正文可读的 `--glass-sheet`，不使用透明度过低的背景。

后续交互统一：榜单和项目阅读选项卡通过 `GlassTabs` 复用同一水滴；容器和水滴折射，文字按钮保持透明。同一榜单范围的视图切换保留组件，避免重建中断动画。快速了解的左右翻页使用一个玻璃胶囊、两个无底图标点击区，关闭按钮独立。

原生选择菜单使用 `display`/`overlay` 的离散过渡保留顶层退出，搜索模式菜单常驻并在关闭时设置 `hidden`、`inert`、`aria-hidden`；两者通过共享 CSS 做 220ms 位移、缩放、裁切及淡出。搜索菜单取消旧的填充入场动画，避免其固定 `opacity: 1` 覆盖淡出。减少动画时即时切换，语义和焦点不等待视觉结束。扩展的视觉脚本实测退出中间帧和中途重新打开；11 项相关回归及生产构建通过。

本次验收：13 项相关浏览器测试、生产构建通过。`node scripts/verify-control-polish.mjs` 使用本地样本验证深浅主题 × 390/1440px 四组页面，检查图标无底、悬停/切换状态、真实展开菜单、选择与 Escape 焦点、不同宽度水滴的中途连续切换、手机换行及减少动画。无页面错误、横向溢出或 POST；截图与结果在 `docs/screenshots/control-polish/`。

实现规则：

- `frosted-glass.css` 是站内控件材质、内边距、字号与状态的统一来源，加载在页面布局样式之后，随后由 `liquid-refraction.css` 注入折射。页面样式只调整布局，不自行清零控件内边距或禁用玻璃。
- 新增文字操作使用 `GlassButton`；现有 `.button` 使用同一尺寸与材质规则。标准最小高度 44px，水平内边距 18px、图标间距 8px；紧凑选项卡在手机保留至少 10px 水平内边距。
- `GlassTabs` 供阅读页与榜单共用：胶囊容器和一个选中水滴保留材质，按钮透明，以文字颜色区分状态。导航、用途分类与它们复用 `useDropletIndicator`，不重复叠加选中背景。
- 新试用页的侧栏、试用列表卡片、工作区等已纳入共享玻璃与折射调度。嵌入软件自身的内部工具栏仍由其编辑器管理。
- 步骤正文通过 `isolation: isolate` 保持独立合成，避免嵌套玻璃控件使普通文字模糊；玻璃滤镜仍保留。手机选项卡不换行，回归检查单行控件高度。
- 白板重复入口、入口所在区域、固定栏目、控件透明度/内边距/折射、手机无溢出都由浏览器回归检查。以后改样式需运行相关检查，而不是仅看单一页面截图。

视觉检查脚本 `scripts/verify-glass-consistency.mjs` 使用确定性页面数据，不调用模型；覆盖发现、榜单、试用列表、生成试用、原生白板、收藏和快速了解。

验收：完整浏览器回归 53/53；最终选项卡及合成修复后相关回归 9/9、中文栏目和唯一入口回归 1/1。生产构建通过（已有大分包提示）。7 类页面 × 深浅主题 × 390/1440px 的 28 组视觉检查全部通过，无横向溢出、页面错误或模型调用。已查看下方白板入口、深浅主题、清晰步骤正文及手机榜单选项卡截图。证据在 `docs/screenshots/glass-consistency/checks.json` 及 `.build/glass-unified-*-final.log`。
