# GitHub 开源观测站

浏览 GitHub 公开项目，先看具体内容，再决定要不要阅读文档或试用。现在可以按需求搜索、观察近期活动，并区分累计榜单和真实历史趋势。卡片、快速阅读、收藏和 Excalidraw 交互试用贯穿这些入口。

最新功能：在任意项目的“快速了解”中点击“生成项目试用”，由 `gpt-6.1-sol` 根据公开 README 制作使用说明与项目专属体验。试用列表可再次打开已生成的内容；支持交互教学、可点击流程图、资料中已有的在线工具和视频入口。Excalidraw 的真实编辑器独立保留，并作为内容规范的参考。详见 [项目试用规范、配置与验证](docs/PROJECT_TRIALS.md)。

当前视觉及接续要求以 [CURRENT_STATUS.md](docs/CURRENT_STATUS.md) 为准；下文部分视觉与验证记录保留历史状态。

当前 UI 已整理为可复用技能 [`silver-liquid-glass-ui`](skills/silver-liquid-glass-ui/SKILL.md)，含完整配色/排版/材质/组件/动画规范、34张实际截图、原始视觉代码和独立起步代码；已安装到本机个人技能目录。使用方法、来源与验证见 [UI风格记录](docs/UI_STYLE_GUIDE.md)。

栏目切换提速：正式服务无人访问时也会准备六个分类及默认榜单前三页，中文卡和完整页面长期保存在服务器本机磁盘，重启直接复用。列表直接附带中文，浏览器一次预取六个分类前三页，切换不再排队生成；新筛选范围自动补齐，更新失败保留完整旧页。实测新浏览器约 0.41–0.46 秒显示中文卡、24 次分类切换 0.9–36.3 毫秒。配置与验证见 [常驻中文项目库](docs/PERSISTENT_CHINESE_LIBRARY.md)，此前浏览器缓存机制见 [交互性能记录](docs/NAVIGATION_PERFORMANCE.md)。

最新提速：仓库列表及“加载更多”不再等待中文概括，已有中文缓存直接返回；AI 搜索逐项展示已核实结果，可停止并保留已返回内容。真实样本普通搜索约 1.05 秒、中文卡约 4.35 秒、AI 首批约 5.81 秒、相同 AI 请求缓存约 4 毫秒。环境与样本会影响结果，配置、验证及边界见 [搜索性能记录](docs/SEARCH_PERFORMANCE.md)。

图片提速：服务端提前下载封面和头像，生成 WebP 缩略图并长期保存在本机，列表直接提供本站图片地址，分类切换提前预取图片。六个分类前三页的 216 个头像已全部走本机缓存；本机实测已缓存图片约 4–38 毫秒，原外网图片约 1–2 秒。后台可查看缓存数量与占用，重启继续复用；尚未缓存或失效的原图自动重试。实现与完整验证见 [图片性能记录](docs/IMAGE_PERFORMANCE.md)。

## 运行

```bash
npm ci
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:5173）。普通 GitHub 搜索无需密钥；AI 需求搜索和中文项目卡共用服务端模型配置。本机已接入官方 DeepSeek `deepseek-flash`，新部署需要自行填写 `.env.local`，缺少凭据时使用普通浏览。

```bash
npm run build
npm start
```

生产服务默认 http://localhost:4173，同时提供静态文件和 GitHub API 代理。也支持 `npm run preview`。静态文件必须与 API 服务一起部署，单独上传 dist 不会提供实时搜索。

Windows 内网运行：构建后执行 `npm run lan:start`，脚本会后台启动正式服务并显示局域网访问地址；`npm run lan:status` 查看状态，`npm run lan:stop` 停止。内网数据独立保存于 `.data-lan/`，首次启动会带上当前已生成的试用和缓存。GitHub 上传、环境配置、防火墙与服务器迁移见 [部署说明](docs/DEPLOYMENT.md)。

简易管理后台：服务启动后在本机打开 `http://localhost:4173/admin`，查看运行与磁盘缓存、各分类中文预热进度，手动安排更新或暂停/恢复后台任务。命令也可从页面复制；管理入口只在服务器本机开放。用法与验收见 [后台说明](docs/ADMIN.md)。

- 四项导航：发现项目、趋势与榜单、项目试用、我的收藏。首页展示搜索、GitHub 近期动态、三个圆点控制的试用轮播与项目浏览；热门开源项目统一从“趋势与榜单”进入。博客及首页三类快捷入口已移除。
- 搜索支持自动识别、GitHub 搜索、AI 需求搜索三种模式。AI 先解析需求，多组查询返回后按份额读取最多 10 个候选的 README，逐项目独立交给 DeepSeek 核对；通过验证即展示，最终汇总最多 8 项。不共享跨项目对话历史，缺少证据的硬条件不进入推荐。GPT 项目试用也按项目独立生成。
- AI 结果支持必须/偏好条件编辑、删除与补充、最多 8 轮追问、证据、未知项、收藏与快速阅读。需求推荐仅在明确提交后触发，可取消和重试；对话只保留在当前页面内，离开即丢弃。本机 DeepSeek 连接和中文卡片生成已通过真实调用验收；自然语言多轮推荐仍需独立验收。
- AI 搜索改为对话页 `#/ask`：空白对话保留简短欢迎语，用户消息靠右，助手以中文项目卡回复；当前页内追问保留历轮回答；从搜索框或项目卡进入都会替换旧对话，同一句话重新搜索也开启新对话，离开、返回或刷新不重放旧消息。输入框固定底部，仅保留文本区与发送按钮，移除底部说明、快捷提问与键盘提示；支持 Enter 发送、Shift+Enter 换行、中文输入法、停止、重试、新对话与滚动到最新回复。需求调整及原文依据折叠显示，保留收藏、居中快速了解及试用项目详情入口；动态状态来自实际服务端进度，包含旋转标记、动态占位、消息与卡片入场及交互反馈，尊重减少动态偏好。在首页选择 AI 模式后，空搜索可直接进入对话欢迎页。
- 发现、收藏和推荐的项目均可通过“快速了解”底部的对话图标与输入栏提问；输入首个问题并发送，直接进入带项目标签的全新问答。切换项目清空草稿，未发送时不调用模型。回答基于该项目 README，追问保留该项目，原文引用折叠显示。服务端复用受保护的推荐接口，按项目隔离缓存，校验公开性及引文；GitHub REST 限流/网络失败时回退匿名公开 README 或带匹配公开标记的 GitHub 正文页，来源不足则明确无法确认。

## 数据与限额

服务端统一管理 GitHub REST、公开页面和 README 原始文件，默认匿名访问。首页三页共用一次 REST 搜索；限流或连接失败时，搜索和仓库资料自动回退公开网页，README 优先读取原始文件与网页。请求节奏、来源冷却及成功响应缓存统一管理，缓存重启后仍可使用。详情见 [GitHub 请求限流处理](docs/GITHUB_RESILIENCE.md)。可选配置：

```bash
# 复制 .env.example 为 .env.local 后按需填写
GITHUB_TOKEN=你的只读令牌
PORT=4173
```

令牌只由服务器读取，不能放到 `VITE_*` 变量中，也不会传给浏览器。GitHub 代理只允许 GET 和固定的搜索、仓库资料、README 端点；仅支持公开仓库。README 先校验父仓库公开性，再读取文档。独立内容服务位于 `/api/observatory/`；AI 提交使用 POST，限制同源、请求大小、频率与同时执行数量。

中文卡片生成对已通过搜索确认公开的仓库优先读取官方 raw README，受网络影响时读取 GitHub 仓库页的 README 正文，再回退 REST API。卡片、阅读和图片共用文档/页面读取；HTML 只提取资料，不执行。模型引用原文片段 ID，服务端绑定实际片段，中文与结构无效时自动修正一次。任务最多同时 4 组、模型生成默认并发 4 张，中文与搜索共用模型总并发 6，单张上限 90 秒；搜索缓存 10 分钟，卡片按项目、模型、简介/主题和协议版本复用，7 天后更新。缓存不占生成队列，存储仍要求单个服务进程拥有 `.data/`。

本机密钥由服务器读取，`.env.local` 与 `api.txt` 均忽略提交。Vite 禁止访问密钥文件及 `.data/.build`，正式服务仅提供 `dist` 目录；已检查客户端构建不包含密钥。

服务器合并重复请求，保留 ETag，并持久缓存搜索（10 分钟）、仓库元数据（1 小时）与 README（6 小时）。上游不可用时最多回退 7 天内的相同查询缓存，保留原采集时间和过期说明；404/无效搜索不会使用过期缓存。网页缺少的字段保持未知，不伪造统计或更新时间。只有初始默认发现页在所有来源不可用时才提供内置资料快照，其他搜索不会用默认快照冒充匹配结果。公开网页也会限流，完全无可用来源时仍提供明确错误和重试提示。

README 使用 React Markdown + GFM，禁用原始 HTML 执行，链接与图片限制为 HTTP(S)，相对链接解析到对应仓库与分支。解读内容基于项目官方 README 和文档；目前仅 Excalidraw 有完整交互解读。
